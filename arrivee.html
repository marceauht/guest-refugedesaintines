Check-in

Retrouvez ici les instructions d'accès pour entrer dans le logement.
Vous êtes déjà garé : il ne reste plus qu'à rejoindre la porte, récupérer les clés et entrer.

Accès au logement

Suivez simplement ces 3 étapes.

1

Trouver la porte

Une boîte à clés est installée à côté d'une porte verte portant le numéro 80.

2

Ouvrir la boîte à clés

Le code de la boîte à clés est : 3105
Refermez bien la boîte en mélangeant le code après avoir récupéré les clés.

3

Entrer dans le studio

  • 🔑 La plus grosse clé ouvre la porte verte n°80.
  • 🔑 Une fois la porte franchie, le studio est sur votre droite (porte blanche) et s'ouvre avec la deuxième clé.
